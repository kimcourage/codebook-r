# CodebookR

코드북에 맞춰 원자료를 정리하고, 분석에 필요한 변수를 준비하는 R Shiny 앱입니다.

코드북의 변수 설명, 응답 코드와 결측값 정의를 실제 자료와 대조합니다. 연구자가 확인하고 승인한 작업만 실행하며, 결과와 함께 같은 처리를 재현할 수 있는 R 코드를 제공합니다.

## 시작하기

R과 RStudio가 설치된 컴퓨터에서 실행합니다. 이 배포본은 R 4.5.2에서 확인했습니다.

1. 이 저장소의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. 폴더 안의 **CodebookR.Rproj**를 열면 RStudio가 시작됩니다.
3. RStudio의 Console에서 처음 한 번 실행합니다. 패키지를 내려받을 인터넷 연결이 필요합니다.

   ```r
   source("install.R")
   ```

4. 다음 명령으로 앱을 엽니다. 다음부터는 이 명령만 실행하면 됩니다.

   ```r
   shiny::runApp(".", launch.browser = TRUE)
   ```

RStudio 없이 사용할 때는 R의 작업 폴더를 이 폴더로 지정한 뒤 같은 명령을 실행하세요. 브라우저 창에서 조작하지만 앱은 내 컴퓨터의 R에서 실행됩니다.

## 사용 순서

1. **자료 연결**: 원자료와 코드북을 함께 올립니다. 먼저 살펴보려면 앱의 예제 불러오기를 사용하세요.
2. **검토**: 변수 연결, 코드북 원문과 실제 값의 차이를 확인합니다. 적용할 작업을 선택하고 미리본 뒤 승인합니다.
3. **결과**: 코드북에 따라 정리된 기본 결과를 내려받습니다. 필요한 경우 여기에 합성변수, 중심화, 표준화 또는 long/wide 변환을 추가합니다. 기본 결과는 별도로 남습니다.

작업 계획은 파일로 저장했다가 같은 원자료와 코드북을 연결해 다시 열 수 있습니다. 다시 연 작업은 검토와 승인을 거쳐 실행합니다.

## 할 수 있는 작업

- 코드북에 명시된 결측 코드 처리, 변수 설명과 값 라벨 적용
- 코드 목록에 없는 값, 범위 밖 값과 서로 다른 정의 점검
- 지정한 척도 범위의 역코딩, 범주형 변환
- 여러 문항의 합계 또는 평균, 최소 응답 문항 수 지정
- 전체, 집단별 또는 개인별 중심화와 z점수 표준화
- 반복측정 자료의 long/wide 변환

원자료는 CSV, SPSS(`.sav`), Stata(`.dta`), RDS를 지원합니다. 코드북은 Excel, CSV, 텍스트가 들어 있는 PDF를 지원합니다.

`examples`에는 가상 자료만 들어 있습니다. 일반 설문 예제는 `synthetic_survey.csv`와 `synthetic_codebook.xlsx`, 반복측정 예제는 `synthetic_panel.csv`와 `synthetic_panel_codebook.csv`를 짝지어 사용하세요.

## AI로 코드북 읽기

검토 화면의 **AI로 코드북 읽기**에서 제공업체와 본인의 API 키를 입력합니다. 전송할 내용을 확인하고 동의하면 코드북 해석을 요청합니다. AI가 읽은 내용도 원문과 대조해 승인해야 적용됩니다. API를 연결하지 않아도 코드북을 직접 검토하고 처리할 수 있습니다.

외부 AI에는 변수명, 자료형, 변수 설명과 코드북 발췌문이 전송됩니다. 원자료의 응답자별 행은 전송하지 않습니다. 코드북과 변수 설명에 민감한 정보가 있다면 전송 전에 확인하세요. 앱은 API 키를 파일에 저장하지 않습니다. API 이용료는 해당 제공업체의 요금에 따릅니다.

## 결과 파일

결과 ZIP에는 정리된 자료(`cleaned_data.rds`), 재현용 R 코드(`preprocessing.R`), 승인한 작업과 변경 기록, 처리 전후 변수 정보, 코드북 대조 기록이 들어 있습니다. 재현용 코드는 원자료를 입력받아 같은 작업을 다시 수행합니다.

## 사용 범위

스캔한 PDF의 문자 인식은 현재 지원하지 않습니다. 복잡한 분기 지침이나 척도별 점수 산정 방식은 원문을 직접 확인하세요. 임의 수식과 가중 점수 계산은 아직 지원하지 않습니다. 연구에 사용하기 전에는 처리 결과와 보류한 항목을 확인하세요.
