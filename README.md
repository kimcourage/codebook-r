# CodebookR

**코드북을 바탕으로 설문자료를 정리하고, 분석에 필요한 변수를 준비하는 R 패키지입니다.**

CodebookR는 원자료와 코드북을 함께 읽어 변수 설명, 응답 코드, 결측값 정의를 대조합니다. 브라우저 화면에서 처리할 작업을 선택하고 적용 전후를 확인할 수 있으며, 승인한 작업만 실행합니다. 정리된 데이터와 함께 처리 과정을 재현할 수 있는 R 코드와 변경 기록을 제공합니다.

## 설치와 실행

R 4.2 이상이 필요합니다. R 또는 RStudio의 Console에서 다음을 실행하세요.

```r
install.packages("remotes")  # 처음 한 번
remotes::install_github("kimcourage/codebook-r")

codebookr::run_app()
```

필수 R 패키지는 함께 설치됩니다. 설치 후에는 `codebookr::run_app()`으로 앱을 열 수 있습니다. 화면은 브라우저에 표시되며, 데이터 처리는 내 컴퓨터의 R에서 실행됩니다. RStudio는 선택 사항입니다.

업데이트하려면 `remotes::install_github("kimcourage/codebook-r")`를 다시 실행하세요.

## 처음 사용하기

앱의 **예제 자료와 코드북으로 살펴보기**를 누르면 파일을 준비하지 않고도 주요 기능을 사용해 볼 수 있습니다.

1. **자료와 코드북 연결**: 원자료와 코드북을 불러오고, 변수 연결과 읽어 온 내용을 확인합니다.
2. **검토와 적용**: 변수별 코드북 근거와 실제 값을 비교합니다. 결측값 처리 등 필요한 작업을 선택하고, 미리보기에서 변화를 확인한 뒤 적용합니다.
3. **결과와 추가 전처리**: 정리된 자료를 내려받습니다. 합성변수 계산이나 자료 형태 변환이 필요하면 기본 결과에 이어서 작업할 수 있습니다.

작업 설정은 파일로 저장할 수 있습니다. 나중에 같은 원자료와 코드북을 연결해 저장한 설정을 불러오면 검토를 이어갈 수 있습니다.

## 주요 기능

| 작업 | 설명 |
| --- | --- |
| 코드북 대조 | 변수 설명, 응답 코드, 결측값 정의를 연결하고 코드 목록에 없는 값이나 허용 범위 밖 값을 확인합니다. |
| 기본 전처리 | 지정한 코드를 결측값으로 바꾸고, 변수 설명과 값 라벨을 적용하거나 역코딩과 범주형 변환을 수행합니다. |
| 합성변수 | 여러 문항의 합계 또는 평균을 계산합니다. 계산에 필요한 최소 응답 문항 수를 지정할 수 있습니다. |
| 중심화와 표준화 | 전체, 집단별 또는 개인별 기준으로 중심화와 z점수 표준화를 수행합니다. |
| 자료 형태 변환 | 반복측정 자료를 long 또는 wide 형태로 변환합니다. |
| 적용 전 미리보기 | 작업 순서에 따른 값, 결측 수, 자료형과 자료 크기의 변화를 확인합니다. |

## 지원 파일

| 구분 | 형식 |
| --- | --- |
| 원자료 | CSV, SPSS (`.sav`), Stata (`.dta`), RDS |
| 코드북 | Excel (`.xlsx`, `.xls`), CSV, 텍스트형 PDF |

여러 코드북을 함께 불러올 수 있습니다. 스캔 이미지로 된 PDF의 문자 인식(OCR)은 현재 지원하지 않습니다.

## 결과 파일

결과는 ZIP 파일로 내려받습니다. 분석에 사용할 데이터뿐 아니라, 어떤 처리를 했는지 확인하고 같은 처리를 다시 실행하는 데 필요한 파일을 함께 제공합니다.

| 파일 | 용도 |
| --- | --- |
| `cleaned_data.rds` | 승인한 작업이 반영된 데이터입니다. R에서 `readRDS()`로 불러와 분석할 수 있습니다. |
| `preprocessing.R` | 원자료에서 결과를 다시 만드는 R 코드입니다. 처리 과정을 검토하거나 공동연구자와 공유할 때 활용할 수 있습니다. |
| `approved_rules.csv`, `audit.csv` | 적용한 작업과 변경 내역을 확인할 수 있습니다. |
| `before_metadata.csv`, `after_metadata.csv` | 처리 전후의 변수 정보를 비교할 수 있습니다. |

코드북 정의와 변수 연결, 대조 결과, 실행 환경 정보도 함께 포함됩니다.

## AI로 코드북 읽기

AI는 코드북의 변수 정의와 처리 지침을 읽는 보조 기능입니다. AI 없이도 코드북을 대조하고 전처리할 수 있습니다.

AI 기능을 사용하려면 다음 패키지를 설치하세요.

```r
install.packages("ellmer")
```

앱의 **AI로 코드북 읽기**에서 OpenAI, Anthropic 또는 Google Gemini를 선택하고 해당 제공업체의 API 키를 입력합니다. 전송할 내용을 확인하고 동의하면 해석을 요청합니다. AI가 제안한 내용도 코드북 근거와 함께 검토한 뒤 적용할 수 있습니다. API 이용료는 제공업체의 요금에 따릅니다.

외부 AI에는 변수명, 자료형, 변수 설명과 코드북 발췌문이 전송됩니다. 응답자별 원자료 행은 전송하지 않으며, 앱은 API 키를 파일로 저장하지 않습니다.
